# huaweicloud-sdk-c-obs

## 更新说明

### 版本 3.26.6

**新特性：**

1. 桶与对象管理：补齐桶清单、桶复制、桶服务端加密（SSE-KMS）、镜像回源、DIS 策略、压缩策略、桶对象锁定（WORM）、公共访问阻断、直读冷存，以及对象标签与对象保留的配置接口（设置/获取/删除）。新增 `put_object_content` 与 `put_file` 简单上传接口，分别支持文本内容与本地文件上传。
2. CRC64 校验：新增对象上传与下载的 CRC64 校验能力（通过上传/下载选项中的 `enable_crc64` 开启，服务器返回的 CRC64 值可在响应中获取），并新增 `obs_compute_file_crc64` 接口用于计算本地文件的 CRC64 值，便于与服务器返回值对比。
3. 列举：`list_objects` 与 `list_versions` 接口支持 `encoding_type` 参数，可对对象与版本 key 字段进行 URL 编码。
4. 自定义头域：支持为请求附加用户自定义头域。
5. 本地地址绑定：支持绑定本地出口网卡/IP 与源端口范围。
6. 国密与双向认证：支持国密模式（SM2/SM3/SM4）与双向证书认证，包括签名/加密证书与密钥路径，以及用于带密码证书的密码回调。

**资料 & demo：**

1. 新增桶与对象管理相关接口描述（桶清单、桶复制、桶加密、镜像回源、DIS 策略、压缩策略、桶对象锁定、公共访问阻断、直读冷存、对象标签、对象保留，以及 `put_object_content` / `put_file` 上传接口）。
2. 新增 CRC64 校验相关接口描述（上传/下载校验与 `obs_compute_file_crc64` 接口）。
3. 新增 `list_objects` 与 `list_versions` 接口的 `encoding_type` 参数描述。
4. 新增自定义头域相关接口描述。
5. 新增本地地址绑定相关接口描述。
6. 新增国密与双向认证相关接口描述。

**修复问题：**

1. 修复列举接口未正确处理对象名包含特殊字符的问题。
2. 修复响应头处理函数中 metadata 数组边界检查错误的问题。

### 版本 3.26.3

> 注意： v3.26.3 仅针对非 Windows 环境优化，不支持 Windows 平台

**新特性：**

1. 自定义域名管理：支持自定义域名的设置、获取与删除，并同步支持相关证书的管理功能。
2. 连接复用：支持 TCP 连接复用（Connection Reuse），有效降低高并发场景下的建连开销，提升传输效率。
3. 依赖升级： 升级第三方依赖包至最新版本，提升稳定性。

**修复问题：**

1. 字符编码修复：解决了在 Linux 环境下，调用“列举桶内对象”接口时出现的中文文件名乱码问题
